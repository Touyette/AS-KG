Why this style's blind spot is structurally unlike the other two. Avoidant patterning is missing emotional information and anxious patterning is missing the analytic kind, so each has a side to develop. Fearful-avoidant has both already — and can only run one at a time. The work is not acquiring anything, it is using both at once, which is exactly what secure people do when they decide which to weight in a given moment.
